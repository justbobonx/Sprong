# SPRONG

Two-player tap tennis on one screen. No paddles. The shockwave is the paddle.

Open `index.html` on a phone. Landscape splits left/right. Portrait splits top/bottom.

## Play

- Neon line splits the wide axis. That is the net.
- Blue is left/top. Red is right/bottom.
- Chevron sits in the server's half and vanishes on the toss tap.
- Toss tap: no shockwave. Ball rises and falls at that point.
- Serve tap: normal shockwave. When the ring reaches the square, it serves. Higher toss = faster.
- Rally taps: same shockwave, player-colored, r=0 fading out to 350px.
- Hit anywhere. The back third of each half is the target. Through the back of a target is a point against that player. Off the side rails is a miss by the last hitter. No wall bounce.
- Winner serves next.

Clicks work for desktop checks. This is a mobile game.
